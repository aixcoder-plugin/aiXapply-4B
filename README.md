# aiXapply-4B

**aiXapply-4B** is a research project for **Full-File Apply**, a code integration task designed for efficient and reliable IDE workflows.

Given an original source file and a localized update snippet, aiXapply aims to generate the complete updated file while preserving all unchanged regions. The project is built around the idea that code integration should be treated as a standalone task rather than only as a byproduct of general code generation.

This repository will host the open-source artifacts for our paper:

> **Fast and Reliable Full-File Code Apply with Specialized Small Models for IDE Workflows**
